# simple-interest-calculator.-Simple Interest Calculator

Project Description

This project is a simple interest calculator that calculates the interest earned on a principal amount over a specific period of time.

Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:

- Principal: The initial amount of money.
- Rate: The annual interest rate.
- Time: The time period in years.

Example

If the principal amount is 1000, the interest rate is 5%, and the time is 2 years:

Simple Interest = (1000 × 5 × 2) / 100

Simple Interest = 100
